## 关键业务链路实测

1. **登录态保持**：连续 3 次 `/auth/me` + 6 个受保护接口，全部 code 0
2. **Token 刷新**：refreshToken 换新令牌，新 token 立即可用
3. **自助注册**：注册即返回 token，默认角色 `PLAYER`
4. **CTF 判分**：错误 flag 判 false；正确 flag 判 true 并首杀加分；重复提交不重复计分
5. **赛事状态机**：非法流转被拦截（SIGNUP → DRAFT 返回 409）
6. **报名约束**：仅 SIGNUP/PENDING 可报名，RUNNING 后拒绝
7. **归档约束**：仅 FINISHED 赛事可归档

## 鉴权验证

- 无 token 访问 `/api/users` → 业务码 `401`「请先登录」
- 401 时前端通过 router 跳转登录页并携带 redirect（已修复 hash/history 混用）
