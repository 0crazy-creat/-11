## 五、说明

- 邮件使用本地 MailHog 承接 SMTP（`1025`/`8025`），验证真实发信链路；生产替换 `csp.notify.mail-*` 即可。
- 短信网关、MQTT broker、LDAP 服务均通过配置开关切换；未配置时降级为本地实现并明确返回 `pending:原因`，便于区分「未启用」与「失败」。
- LVP 使用内存实现验证接口与状态机；生产可替换为 docker-java/libvirt，接口契约不变。
- ABAC 支持 `orgCode` / `userId` / `username` 属性，`${param}` 占位从方法参数或请求参数解析。
