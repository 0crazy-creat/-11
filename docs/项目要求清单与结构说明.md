## 二、项目结构（分层 + 按域拆分）

```
网安平台项目/
├─ backend/                        # Spring Boot 多模块
│  ├─ csp-common/                  # 通用：Result/PageResult/BizException/BaseEntity/JacksonConfig/IpUtils
│  ├─ csp-security/                # 认证鉴权：JWT、RBAC、ABAC(@RequireAttribute)、拦截器
│  ├─ csp-infra/                   # 基础设施：Redis、Docker、WebSocket、Mongo
│  ├─ csp-platform/                # 平台底座：用户/角色/赛事/题库/战队/通知/审计/归档/导出/Writeup
│  │  ├─ controller/               # 对外 API
│  │  ├─ service/                  # 业务逻辑
│  │  ├─ entity/ mapper/ dto/      # 持久化与传输对象
│  │  ├─ notify/                   # 通知渠道（INBOX/EMAIL/SMS）
│  │  ├─ virt/                     # LVP 虚拟化、集群 SLA、SSO/LDAP、MQTT、ABAC 演示
│  │  └─ config/                   # SPA 转发、限流、Jackson
│  ├─ csp-ctf/                     # CTF 子系统：赛事题目、提交判分、反作弊、理论赛、报名
│  ├─ csp-awd/                     # AWD/AWDP：轮次状态机、攻防计分、靶机编排
│  └─ csp-situation/               # 态势感知：总览、排行、大屏、飞线回放、战队主页
├─ csp-arena/                      # 独立靶场服务（端口 11002）
│  ├─ backend/                     # Docker 调度、模板/实例管理、健康巡检
│  └─ deploy/                      # targets 镜像定义、arena 库 SQL、验证脚本
├─ frontend/                       # Vue3 + Vite
│  └─ src/
│     ├─ layouts/                  # PortalLayout(选手端) / ConsoleLayout(管理端) / PlayLayout
│     ├─ views/
│     │  ├─ auth/                  # 登录/注册
│     │  ├─ portal/                # 选手端：赛事大厅、我的比赛、答题、题解社区
│     │  ├─ console/               # 管理端：控制台、用户、公告、审计
│     │  ├─ contest/               # 赛事管理、题库管理、战队管理
│     │  ├─ awd/ situation/        # AWD 大屏、3D 态势、排行、战队主页
│     ├─ api/ utils/ store/ router/# 接口封装、请求、状态、路由
│     └─ styles/                   # 视觉规范（主色 #295FFF）
├─ deploy/
│  ├─ sql/                         # 01 schema → 10 cleanup/seed（按序执行）
│  └─ scripts/                     # e2e_verify.py、api-full-test.sh、ui-*.cjs
└─ docs/                           # 需求清单、验收报告、README
```

### 关键结构决策

1. **前后端分离 + 单端口部署**：后端托管 SPA（`SpaWebMvcConfig` 显式路径转发），避免自定义 `PathResourceResolver` 与 Spring Boot 3 冲突。
2. **选手端/管理端彻底分离**：`/portal/**` 与 `/console/**` 两套 Layout + 路由守卫按 `permissions` 校验；管理菜单按权限动态渲染。
3. **ID 全链路字符串化**：雪花 ID 超出 JS 安全整数，`JacksonConfig` 统一 `Long → String`，避免精度丢失导致"打不开题目"。
4. **按域拆分模块**：CTF/AWD/态势各自独立模块，共享 `csp-common`/`csp-security`，避免循环依赖。
5. **靶场独立服务**：`csp-arena` 单独进程 + 独立库 `csp_arena`，与主平台解耦，可独立扩缩容。
